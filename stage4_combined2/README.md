# Tab31 반영 4단계 계산자료

생활비 450·월 준비여력 300·초기 비상현금 2,700만 원의 기존 합본2 계산을 수정했습니다. 월 5만 원 정산 유보 가정을 삭제하고 29개 대안과 대출 경계를 다시 계산했습니다. 실제 정산액은 확인된 금액·납부일에 별도 지출로 반영합니다.

고정 대출안의 총현금·월수지·순자산은 바뀌지 않습니다. 종전 유보액은 소비가 아닌 현금 내부 분류였으므로, 삭제해도 월소득이나 월수지에 5만 원을 더하지 않습니다. 기본 12개월의 60만 원, 복직 지연 18개월의 90만 원을 별도로 묶어 두지 않게 됩니다.

## 재계산

Python 3.10 이상, 외부 패키지와 네트워크 없이 실행합니다. 검증 환경은 Python 3.13입니다.

```powershell
python 전체재계산.py
python -m unittest discover -s tests -v
```

`prepare_profile.py`는 이전 엔진에서 복사본을 처음 준비한 기록입니다. ZIP을 받은 뒤 일반 재계산에는 필요 없습니다. 계산은 이 폴더의 입력·코드만 사용합니다.

단위 미만 반올림으로 인해 세부 항목의 합과 총계가 일치하지 않을 수 있음. 총계는 반올림 전 원자료의 합계를 유지합니다. 비율은 소수 첫째 자리, 세금·원리금 납부 표시는 별도 원 단위 파일을 사용합니다.

매월 현금에서 생활·돌봄비와 주택 원리금의 6개월분, 미집행 출산비의 현금부담과 출산 예비비, 취득 후 거래 예비비 200을 남깁니다. 비상목표는 이전 달보다 낮추지 않습니다. 잔금 시점에는 출산비 집행이 끝나 미집행 출산비·출산 예비비는 0입니다.

대출 경계는 2031.6까지 잔금·취득 후 월말에 위 필요자금을 모두 남기는 최소 1만 원 단위 금액입니다. 계약금과 은행 승인은 별도로 확인합니다. 2027년은 계약금 후 약 58만 원 부족하고, 세 구입시점 모두 매입 후 5년 연장기간에 비상·목적자금을 전액 남기지 못하는 달이 발생합니다.

코드의 `reserve`는 비상현금, `future_birth_cash`는 미집행 출산 현금부담, `birth_buffer`는 출산 예비비, `trade_buffer`는 거래 예비비입니다. `earmark`는 비상현금 이외 목적자금의 합계, `free`는 총현금에서 비상·목적자금을 모두 남긴 뒤 추가 배분할 수 있는 차액입니다. 이 호환 필드명은 새로운 전략 이름이 아닙니다. `settlement_balance`와 `settlement_retained`는 이번 29개 대안에서 모두 0입니다.

## 취학 후 민감도

2028.4 출생아의 일반적인 취학을 2035.3으로 가정하고, 복합예산보다 반복비용이 월 5·20·50 늘어나는 경우를 시험했습니다. 순증액은 현금지출과 비상목표 6개월분에 모두 반영합니다.

| 월 순증 | 2036.6 월수지 | 취학 후 첫 월적자 |
|---|---:|---|
| 5 | -3 | 2036.4 |
| 20 | -18 | 2035.3 |
| 50 | -48 | 2035.3 |

세 시험 모두 매입 후 전체기간에 비상·목적자금을 남긴 차액의 최저값은 잔금일 약 941만 원입니다. 현금이 남아도 반복 월수지가 약해질 수 있습니다. 순증액은 실제 학교 비용·돌봄 견적이나 평균이 아닙니다. 실제 예산을 확인하면 어린이집 10을 종료하고 학교·급식·방과후·돌봄·교육 항목으로 대체하며 기존 80·60과 겹치는 항목을 정리합니다. 확정 예산은 현재 `UNKNOWN`입니다.

## 확인 범위

13개 검사는 현금 보존식, 독립 원리금·취득비용 산식, 비상목표, 대출 경계와 1만 원 미만 실패, 유보 삭제 전후 현금·월수지 불변, 취학 민감도, 표시 반올림 분리를 확인합니다.

복합시험은 복직 6개월 지연·신규금리 7.0%·유료 보조 및 공백 돌봄 20.0% 상승·주식매각가 20.0% 하락·갱신보증금 1,500 증액입니다. 돌봄 상승은 월 20/60에만 적용합니다. 부모지원·보증금 반환 지연은 별도 시험입니다.

원 단위 비용·상환표는 가상 사례의 무반올림 산식을 표시한 것으로 실제 세금고지서나 은행 확정 상환표가 아닙니다. 대출 승인·매물 적합성·실제 입출금일·실행일 제도·노후 충분성은 미확인입니다. 5.6억·1.45억은 비교한 조합 중 우선 검토안이며 확정 매입가능액이 아닙니다.
