# AFPK 4단계 재무설계안 계산 결과

사례: kim-lee-fictional-2026 / 기준잔액일: 2026-11-30 / 단위: 만 원

## 4.1 설계 원칙

진료·회복·필수 돌봄과 비상현금을 우선 확보하고, 월 100만 원의 은퇴저축을 유지하며 주택 조건을 비교한다. 현금 부족, 보호자금 위반, 월수지 적자는 별도로 표시한다.

아래 결과는 입력한 가상 사례와 제도 스냅샷의 계산이다. 실제 대출·매물·송금·임대차·실행일의 제도 확인을 대신하지 않는다. 장기 연장은 명목급여·비용 구성을 유지한 민감도이며, 노후자금 충분성은 미평가다.

## 4.2 자금배분과 현금흐름

현재 정기 세후소득은 850.00, 생활비는 480.00, 은퇴저축은 100.00다. 정산 유보금은 보유 현금이며 별도 소비로 차감하지 않는다. 바우처는 현금입금이 아니다.

월별 장부는 `monthly_cashflow.csv`, 개별 사건은 `event_liquidity.csv`, 계약·잔금 요약은 `transaction_summary.csv`, 보호자금 구성은 `protected_funds.csv`에서 확인한다.
